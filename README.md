# Eskişehir Technical University Website

Eskişehir Technical University için hazırlanmış, statik ve gayriresmî bir BIM222 ödevi web sitesidir.

## Çalıştırma

Herhangi bir web sunucusu gerektirmeden `home.html` dosyasını tarayıcıda açabilirsiniz. İsterseniz projeyi bir statik web sunucusuyla da yayınlayabilirsiniz.

## İçerik

- Üniversite, akademik bilgiler ve kampüs yaşamı sayfaları
- Öğrenci hizmetleri için dış bağlantılar
- Yerel HTML, CSS ve görsel dosyaları

## Notlar

- Bu proje Eskişehir Teknik Üniversitesi'nin resmî web sitesi değildir.
- Giriş sayfası yalnızca görsel/demo amaçlıdır; gerçek kimlik doğrulama yapmaz.
- Bootstrap ve Google Fonts harici CDN kaynakları olarak kullanılmaktadır.

## Lisans

Bu projenin kendi kaynak kodu MIT Lisansı altında sunulmaktadır. Üçüncü taraf marka, görsel, yazı tipi ve harici içerikler kendi sahiplerinin haklarına tabidir.
